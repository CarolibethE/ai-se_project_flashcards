      About Flashcards

      Flashcards is a study app that allows users to create, review, and practice custom decks.

      Decks are represented using JSON in this format:

      {
  "name": "JavaScript Basics",
  "cards": [
    {
      "question": "What does DOM stand for?",
      "answer": "Document Object Model"
    }
  ]
}
