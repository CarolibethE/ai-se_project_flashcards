# FLASHCARD APP

## Overview

My first project in TripleTen's AI-Assisted Software
Engineering program. It includes decks of flashcards,
each of which can be viewed in a carousel. It is a study application that allows users to create and manage decks of flashcards, review individual cards, and practice with an interactive carousel. The project includes responsive design, API integration, modal-based error handling, and documented JavaScript functions.

## Features

Home View
- Displays all flashcard decks in a responsive grid layout.
- Shows the deck name and number of cards.
- Allows decks to be deleted.

Open Deck View
- Displays all cards belonging to a selected deck.
- Allows users to flip cards to view answers.
- Allows cards to be deleted.
- Includes a Practice button that opens the carousel study mode.

Carousel Practice View
- Displays one flashcard at a time.
- Navigate between cards using previous and next buttons.
- Flip cards to reveal answers.
- Navigation buttons are disabled when the beginning or end of the deck is reached.

Create New Decks View
- Creates new flash card decks directly from the application
- Each deck contains its own set of cards and can be opened individually for viewing and practice.

Responsive Design
- Layout adapts to mobile, tablet, and desktop screen sizes.
- Card grids resize appropriately on smaller screens.
- Mobile action buttons remain fixed at the bottom of the screen.
- Carousel layout adjusts for smaller viewports.

Confirmation Modal
- Helps prevent accidental deletion of decks or cards by requiring the user to confirm the action before the item is removed

JSDoc Documentation
- Documents all named JavaScript functions with JSDoc comments

During this project, I practiced building a multi-view JavaScript application and connecting the interface to remote data. I gained experience creating decks and cards, handling API requests, displaying application errors through modals, building responsive layouts, and documenting JavaScript functions with JSDoc.

The project also helped me improve my understanding of reusable code, DOM manipulation, asynchronous JavaScript, routing, and user-focused error handling.
